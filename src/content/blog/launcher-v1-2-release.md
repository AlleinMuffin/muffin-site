Muffin Launcher v1.2 发布了。这次的重点是**让"更新整合包"变成一件不用想的事**。

## 增量同步

v1.1 每次都整包校验，128 个模组要跑将近一分钟。v1.2 改成比对指纹后只下载变化的部分，实测：

```text
v1.1   首次 58s   后续 52s
v1.2   首次 58s   后续 6s
```

首次没有变化，因为该下的还是得下；但后续更新从一分钟压到几秒。

## 启动参数预设

可以在配置里给不同整合包指定不同的 JVM 参数：

```json
{
  "profiles": {
    "latest": { "memory": "6G", "javaArgs": ["-XX:+UseG1GC"] },
    "light": { "memory": "3G", "javaArgs": [] }
  }
}
```

低配机器可以切到 `light`，不用手动改启动器设置。

## 安装包瘦身

去掉了一个只用来解析 YAML 的依赖（实际只需要读几个字段），安装包从 82MB 降到 24MB。

## 已知问题

- macOS 版还没签名，首次打开需要在系统设置里允许
- 多版本 Java 的自动识别在部分发行版上会选错，临时方案是在设置里手动指定路径
