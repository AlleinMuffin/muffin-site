整合包最烦的时刻不是装，而是**更新**：服务端升了一个模组，客户端没跟上，玩家进服就崩。

## 之前的做法

维护一份 `mods.txt`，谁更新了就在群里喊一声，大家手动下载替换。问题是：

- 有人不看群
- 有人下错版本
- 出问题时分不清是模组还是配置

## v0.3 做了什么

改成脚本直接比对服务端与本地的模组指纹：

```bash
muffin check --server play.simpfun.cn:32883 --profile latest
```

输出大致是这样：

```text
✔ 128 mods 已同步
! 3 mods 需要更新
    create-1.21.1-6.0.4   →   6.0.6
    jei-1.21.1-19.0.1     →   19.0.3
    sodium-1.21.1-neo-2.0 →   2.1
```

只对变化的三条做下载，其余不动。

## 还差什么

- 配置文件（`.cfg` / `.toml`）的合并目前还是覆盖式的，会丢玩家的自定义设置
- 没有回滚：更新失败只能手动恢复备份

下一步打算把配置合并做成三向 diff，失败自动回退。
